# 💰 US Paycheck & Withholding Estimator

A simple web-based tool that estimates **U.S. paycheck deductions and take-home pay** based on annual salary, pay frequency, and filing status.

## 📌 Features

* 💵 Enter annual gross salary
* 📅 Choose pay frequency:

  * Weekly
  * Biweekly
  * Semi-monthly
  * Monthly
* 👤 Select filing status:

  * Single
  * Married Filing Jointly
* 🏛️ Estimate federal income tax
* 🛡️ Calculate Social Security and Medicare
* ➕ Calculate Additional Medicare Tax when applicable
* 💰 Show estimated net (take-home) pay
* 📊 View the tax calculation breakdown
* 📱 Responsive design for desktop and mobile

## 🛠️ Technologies

* **HTML5**
* **CSS3**
* **JavaScript**

## ⚙️ How It Works

```text
Annual Salary
      ↓
Pay Frequency + Filing Status
      ↓
Federal Tax Calculation
      ↓
Social Security + Medicare
      ↓
Estimated Net Pay
```

The calculator uses **2026 U.S. federal tax figures**, including tax brackets, standard deductions, and Social Security/Medicare rates.

## 🚀 How to Run

1. Clone the repository.
2. Open `US_Paycheck_Withholding_Estimator.html` in a web browser.
3. Enter your salary and select the required options.
4. View your estimated paycheck breakdown.

No backend or installation is required.

## ⚠️ Disclaimer

This is an **estimation tool for informational purposes only**. It does not include state/local taxes, W-4 adjustments, benefits, or other deductions.
